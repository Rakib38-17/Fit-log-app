Project Name : Fit Log

Short description :
 Fit-Log is a responsive fitness work management web . this application built with Next.js, TypeScript, React, and Tailwind CSS. Users can explore exercises, view detailed workout information, add exercises to their daily plan, save favorite workouts, track workout duration and calories, and manage their plans through a dynamic dashboard.

Technologies used :
Next.js – App Router and page routing
React – Component-based UI development
TypeScript – Type-safe development
Tailwind CSS – Responsive styling
JSON –  data management

5 key features of the project :
Exercise Discovery – Browse and explore exercises with details like muscle groups, equipment, difficulty, duration, and calories burned.
Workout Details – View detailed exercise instructions, descriptions, sets, reps, and ratings.
Daily Workout Plan – Add exercises to a personalized daily workout plan and manage them easily.
Save Favorite Workouts – Save exercises for later and access them from the Saved Plans section.
Workout Tracking & Sorting – Track workout duration and calories while sorting exercises by duration, calories, or rating.
